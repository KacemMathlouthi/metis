# Code of Conduct

Metis follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, give and accept constructive feedback, and focus on what is best for the project. Harassment, personal attacks, discriminatory language, and publishing other people's private information are not tolerated, in project spaces or when representing the project elsewhere.

Maintainers may remove contributions or restrict participation that violates these standards.

To report a problem, contact [@KacemMathlouthi](https://github.com/KacemMathlouthi). Reports are handled promptly and confidentially.
